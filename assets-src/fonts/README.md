# فونت‌های کامل (نسخه‌ی اصلی)

فایل‌های این پوشه نسخه‌ی کامل و دست‌نخورده‌ی فونت‌ها هستند و **سرو نمی‌شوند** — بیرون از
`wwwroot` نگه داشته می‌شوند تا هر وقت خواستیم زیرمجموعه را از نو بسازیم.

آنچه در `wwwroot/fonts` قرار دارد، زیرمجموعه‌ی همین فایل‌هاست: حروف فارسی، لاتین پایه و
نشانه‌گذاری‌هایی که یک صفحه‌ی فارسی واقعاً استفاده می‌کند. بلوک «اشکال نمایشی عربی»
(U+FB50–FEFF) حذف شده چون یک بلوک سازگاری قدیمی است و متن این سایت یونیکد معمولی است.

نتیجه (پیش از فشرده‌سازی سرور):

| فونت | کامل | زیرمجموعه |
|---|---|---|
| Vazirmatn-Regular | ۵۰٬۶۸۴ | ۲۸٬۴۳۶ |
| Vazirmatn-Medium | ۵۱٬۱۲۸ | ۲۸٬۹۷۲ |
| Vazirmatn-SemiBold | ۵۱٬۰۳۲ | ۲۸٬۸۹۶ |
| Vazirmatn-Bold | ۵۱٬۰۲۰ | ۲۸٬۹۸۸ |
| Lalezar-Regular | ۸۳٬۶۴۰ | ۲۷٬۶۰۸ |
| Gulzar-Regular | ۲۳۶٬۶۳۶ | ۱۹۸٬۲۲۸ |

روی هر فونت با HarfBuzz آزمایش شد: شکل‌دهی و مکان‌یابی ۱۳ سطر نمونه‌ی فارسی (شامل
نستعلیق، ارقام فارسی، گیومه، خط تیره و لاتین) با نسخه‌ی کامل **بایت‌به‌بایت یکسان** است و
هیچ نویسه‌ای به .notdef نمی‌افتد.

## بازسازی

با `pip install fonttools brotli`:

```bash
RANGES="U+0020-007E,U+00A0,U+00AB,U+00BB,U+0600-06FF,U+200C-200F,U+2010-2015,U+2018-201F,U+2026,U+2030,U+20AC,U+FEFF"

pyftsubset Vazirmatn-Regular.woff2 --output-file=Vazirmatn-Regular.woff2 --flavor=woff2 \
  --unicodes="$RANGES" --layout-features='*' --no-hinting --desubroutinize
```

`--layout-features='*'` حذف‌شدنی نیست: نستعلیق کل شکل‌دهی‌اش از جدول‌های GSUB/GPOS می‌آید و
با هرس‌کردن ویژگی‌ها، حروف به‌هم نمی‌چسبند.

پروانه‌ی فونت‌ها (OFL) همراهشان در `wwwroot/fonts` می‌ماند؛ زیرمجموعه‌گیری طبق OFL مجاز است.
